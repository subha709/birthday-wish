# Birthday Wish Project 🎈

A beautiful, interactive birthday greeting website featuring:
- ✨ **Glassmorphism UI**: Modern and sleek design.
- 🎊 **Confetti Cannon**: Interactive celebration trigger.
- 🎈 **Floating Balloons**: Dynamic background animations.
- 📱 **Responsive**: Works on mobile and desktop.

## How to Run Locally
1. Clone this repository.
2. Open `index.html` in any web browser.

## Deployment
This project is ready to be hosted on **GitHub Pages**. Just enable it in your repository settings!
